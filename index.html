Conhecimentos

HTML

HTML é uma linguagem de marcação de hipertexto, que usamos para marcar os elementos da página e construí-la.

CSS

CSS é uma linguagem de estilo usada para descrever a apresentação dos elementos da página os estilizando.

JavaScript

JavaScript é uma linguagem de programação interpretada usada no desenvolvimento web para descrever funcionalidades e comportamentos da página.

PHP

PHP é uma linguagem de programação server-side amplamente usada para desenvolvimento web dinâmico, permitindo a criação de páginas e aplicações interativas.

PYTHON

Python é uma linguagem de programação de alto nível, conhecida por sua simplicidade e versatilidade, usada para desenvolvimento web, ciência de dados, automação e muito mais.

Java

Java é uma linguagem de programação orientada a objetos, usada para desenvolver aplicações robustas, seguras e multiplataforma.

Go (Golang)

Go é uma linguagem compilada e concorrente desenvolvida pelo Google, ideal para APIs REST, microsserviços e sistemas de alta performance.

TypeScript

TypeScript é um superconjunto tipado do JavaScript que compila para JS puro, trazendo tipagem estática e maior produtividade no desenvolvimento.

React

React é uma biblioteca JavaScript para construção de interfaces de usuário componentizadas e reativas, amplamente usada no desenvolvimento web moderno.

Node.js

Node.js é um ambiente de execução JavaScript server-side que permite construir aplicações escaláveis e de alta performance com event-loop assíncrono.

Solidity

Solidity é uma linguagem de programação orientada a contratos inteligentes para a plataforma Ethereum, usada no desenvolvimento de dApps e blockchains.

C#

C# é uma linguagem de programação moderna e robusta da Microsoft, utilizada para desenvolvimento de aplicações desktop, web, jogos e mobile.

Docker

Docker é uma plataforma de conteinerização que permite empacotar, distribuir e executar aplicações de forma leve, portável e isolada.

SQL

Experiência com bancos relacionais e NoSQL: MySQL, PostgreSQL, MongoDB e SQLite — modelagem, consultas complexas e otimização de performance.
